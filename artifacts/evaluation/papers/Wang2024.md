## Notes

- **Survey scope**: Wang et al. compare 8 tools on 4 benchmark Java applications (JPetStore, Spring-PetClinic, PartsUnlimitedMRP, 7ep-demo). Tools were selected from 24 publications identified in a systematic review (CORE A*/A venues, published before January 2024). Tools requiring unavailable artifacts (ER diagrams, use case diagrams) were excluded.
- **Mono2Micro** is a commercial IBM product. The research prototype described in Kalia et al. 2021 (FSE) is not publicly open-sourced. IBM provides access at https://www.ibm.com/docs/en/mono2micro. No repo found after searching IBM GitHub orgs and Anup Kalia's profile.
- **HyDec** was found via the first author's GitHub (`khaledsellami`). The repo description explicitly matches the ICSOC 2022 paper.
- **CARGO** is implemented as part of IBM's Konveyor project under the name `tackle-data-gravity-insights`. The repo is the open-source version of the tool described in Nitin et al. 2023 (ASE).
- **MEM** (Microservice Extraction based on Microservice Metrics) by Mazlami et al. 2017 has two separate repos: a backend (Java, the extractor) and a frontend.
- **Data-Centric** repo owner `otiber` is Okba Tibermacine, one of the co-authors of Romani et al. 2022 (ICSA-C).
- **MOSAIC** repo is under the `sosygroup` GitHub organization (University of L'Aquila group). The repo description is an exact match for the paper title.
- **Log2MS** and **toMicroservices** had no publicly discoverable repositories after exhaustive search (tool name, paper title keywords, author username variants, DOI artifact pages). See below for manual lookup references.
- The study artifacts page (results, metrics scripts, case study decompositions) is at: https://resess.github.io/artifacts/MicroserviceToolStudy/
- All tools target Java applications. The single Python tool found in the survey was excluded from the comparison.
- **Granularity**: Mono2Micro, HyDec, Data-Centric, Log2MS, MEM operate at class level; toMicroservices, CARGO, MOSAIC operate at method level (MOSAIC also has class-level capability).
